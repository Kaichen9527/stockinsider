# 上櫃法人成交股數與全時段成交量的定時採集

將政府登錄資料 11856 及 11370 加到既有 Contabo staging 的 21:28 採集。每個來源均檢查固定表頭、原始報表日、唯一代號和可用數值；法人原始股數另外驗買減賣及分項合計。檔案僅於交易日及原截止內有效才留作即時取樣，與原 21:26 和 21:27 觀測分開。資料時鐘、原始雜湊和檔案實測見 [收據](../../docs/operations/2026-11-15/launch-radar/contabo-stage-tpex-stock-flow-and-turnover-armed.json)。

11/13 事後演練，11856 有 896 個完整代號，11370 有 13,807 筆有價證券，其中 6,103 筆有正成交股數與金額。兩個報表接合有 896 個代號，包含 5274／6488。政府登錄資源與指定日期全時段報表的位元相同；回讀三份保存檔均通過 SHA-256。提前進入 11/16 即時模式於連線之前拒絕。用量峰值約 56 MiB，低於現場既有 96 MiB 上限。正式 11/16、11/17 尚待到場執行。

這份 11370 供同口徑法人占量分母及原生成交額使用，原 11371 用於相同規格技術序列。上櫃行情含其他證券；正式候選仍經型別、事件、交易日、公司行動、來源範圍及合格名冊檢查。這輪沒有觸發正式 writer。

同一 staging 的舊 collector 留存，替換檔的 SHA-256 與 Git commit 一致。既有兩個 21:28 timers 包含實際日期、起始、資源及非特權設定，前後皆相同。[櫃買法人明細 11856](https://data.gov.tw/dataset/11856) · [櫃買全時段報表 11370](https://data.gov.tw/dataset/11370)
