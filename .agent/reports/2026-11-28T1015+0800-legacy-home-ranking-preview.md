# StockInsider 舊版首頁驗收

GitHub #418 的 Mac 預覽預設開「每日榜單」，保留股票研究原三分類、主題分析及社群發現。凍結榜單讀取沿原公開契約。沒有可讀榜時顯示缺件，並呈現原公開快照的候選。點入時帶入快照發布時間及個股研究版本，不接受錯版。

11 月 28 日唯讀查核公開舊雷達，市場資料日期為 2026-09-12，313 檔來源命中、1 檔等待、0 檔可行動。以同一發布時間讀通全部分類的分頁，逐頁核對數量和代號不重複。外接 2026-09-19 正式備份 GCM 驗證後串流讀出 262 筆舊版快照，最近的每日快照同為 2026-09-12，檔案中沒有新版凍結榜資料表。公開紀錄及備份均無法提供新版榜單。Contabo staging 現場未讀回。

Mac 以固定公開資料副本測試，沒接正式寫入。1440×900 與 390×844 Chromium 均驗首頁預設、候選個股同版摘要、返回、股票研究分類、第二頁及錯版 409，無水平溢出。台積電曾從公開個股 API 按原研究版本讀回 14 項公開事實，市場舊快照與個股研究日期分開解讀。本地預覽只接公開候選摘要，完整個股與已發布真榜驗收仍由原卡追蹤。23 項定向測試、檔案 lint、Mac production build 和 92/92 靜態頁通過。

OpenSpec 2.2.0 已與上游版本核對，以官方 CLI 產出 Codex 專案技能，保留原技能。SWE-agent 1.1.0 已在外接隔離環境安裝，CLI 可啟動。AutoGPT Platform beta 0.12.1 已取得固定版本。兩者的模型提供者仍待有權限的設定。審查、CI、兩個真正發榜交易日與正式部署保持未驗。
