# T06 and T10 cutoff roster collection

Contabo staging has one isolated roster collection per scheduled Taiwan session on November 16 and November 17 at 21:24 Asia/Taipei. Each checks the current official company and custody files before the 21:30 cutoff. The existing six staging timers and every other timer in the host inventory matched before and after this addition. [Collector commit](https://github.com/Kaichen9527/stockinsider/commit/2596970c6054ec3111caa7a8b5aea5d4f7b72c1d)

The private capture keeps response timestamps, SHA‑256 and a minimal reconciliation of code, listing date and differences. A late capture, mixed source dates, missing file or header drift cannot create a review projection. Raw files and contact fields stay out of Git and staging state. A matching snapshot still needs exchange listing and trading status and an approved registry manifest before it can contribute to market breadth.

Pinned Node v22.14.0 passed 20 tests including the new private projection test. The dated staging collector also completed a real read of all three licensed files in rehearsal. Its process peak was about 198 MiB and it correctly refused the Friday cutoff using the later source documents. The live path refused an early launch before opening the network or state directory. Two live captures remain pending. None of this invokes the application writer, validates a full session or changes the production release.
