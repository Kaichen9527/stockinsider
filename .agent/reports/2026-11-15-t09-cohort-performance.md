# T09｜首次與連續上榜的成效統計

Top 10 連結至 `/launch/performance`。報告按最新已發布榜單交易日往回包含 365 個曆日，顯示相同觀測截點下的首次上榜與連續上榜。每份凍結榜單中的同一股票只取已保存的最新成效版本。出榜後再進榜，沿用既有訊號表的分組規則建立新一輪。成效版本歷史與原榜單繼續保存。

研究與開盤模擬分開。研究的分母是已納入追蹤的上榜訊號。開盤狀態分為模擬成交、無法成交、等待開盤、證據不足與等待觀測。模擬報酬與門檻表只計入已模擬成交的樣本。標示未到期、觸價順序不明及缺資料。20／60／120 日顯示各自的有效筆數、平均報酬與同市場超額，超額另列實際有基準的筆數。

讀取走既有 vNext 模式與 service role 的唯讀公開投影，不傳輸訊號原文、私有證據、行情封包或操作憑證，不觸發研究或排程。資料庫拒絕直接匿名呼叫，前端遇到資料形狀或分母不一致時保留不可用狀態。

## 隔離驗證

- PostgreSQL 17.11 以合成榜單證明初次／連續上榜分組、同一訊號兩個版本只計一次、無法成交不進入模擬報酬、未觀測單獨計數，以及公開輸出包含正確的同市場平均超額。以唯讀交易執行，未增加資料。實際 TypeScript 讀取器成功解析資料庫輸出。
- 47 個 Node.js 測試及相關檔案的嚴格 TypeScript 5.9.3 檢查通過。含 5 個新增案例，驗證資料形狀、缺口、零值、React HTML 顯示及功能關閉時沒有資料庫讀取。補丁套用及檔案雜湊已核對。
- 這次測試使用隔離 PostgreSQL 與 React 靜態渲染。整站建置、桌機／手機、正式寫入量測、真實開盤和正式發榜仍待驗收。正式服務未變更。
