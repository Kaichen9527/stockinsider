## Verified

- In PostgreSQL 17.11 the original author acquired the version marker through the existing RPC. The same versioned OpenAPI packet emitted by Node passed prepare and replay. A different synthetic author and an old writer packet were refused. The historical preparation kept its input hash and gained zero new binding rows.
- The bounded grant allowed the data owner to read one completed synthetic acquisition. Its queued sibling, ungranted internal column and table-wide SELECT were excluded. Four role checks against each of eleven functions confirmed 44 direct EXECUTE denials.
- The original homepage projection excluded raw binding fields. Work-context produced no audit writes. One-byte preimage drift stopped installation and rollback removed the staged table, new functions, and new acquisition grant.
- The cluster used a disposable local Unix socket in an isolated Contabo process. Source rows used synthetic fixtures and the rights, structural document and writer lease checks in this fixture are test doubles. This evidence covers the SQL integration and owner boundary. It does not cover production writer identity, external model dispatch, full live-source coverage or the current protected release gate.
