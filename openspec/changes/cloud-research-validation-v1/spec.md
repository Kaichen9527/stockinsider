# Approved Cloud-primary validation amendment

The user approved Cloud-primary StockInsider research/development, VPS durable
production state/results and transitional Mac browser/review/backup dependencies.
This dependent PR supplies a portable bounded work/result contract, a separate
Cloud-only capacity profile and an explicitly started deterministic finance
validation CLI. It does not claim the six-role model dispatch or real publication
pipeline is complete, replace the protected Mac runner, or activate schedules.

A trusted controller creates packets only after existing job/reservation claims
and rights-aware evidence projection. Bind role, job/attempt/reservation/owner,
exact source commit, cutoff-visible evidence, maximum30-minute same-Taipei-day
expiry and content/input hashes. Cloud receives permitted evidence summaries,
never credentials, cookies, private/member full text or formal approval keys.
Original controller-held input is required for result verification; result-provided
input or hashes are never authority. The receiver rechecks math with the existing
article validator; immutable replay and live lease acceptance remain the existing
endpoint/database responsibility, not a new local publication store.

Cloud profile:20 GB resident,4 GB temporary,8 GB free reserve, measured8 GiB RAM
peak target and one sandbox heavy-task lock. No production Contabo guard changes.
Unknown per-project quota remains explicit. Read current Linux/cgroup/statfs/du
observations at admission; shared overlay df is not a per-project guarantee.

Acceptance must test temporal/source/role/hash substitutions, expired lease,
future/withdrawn evidence, negative EPS, changed math, JSON/secret bounds, source
checkout mismatch, output overwrite, disk/quota/memory limits and lock contention.
Actual Cloud artifact execution is separate from local fixtures. Until the
platform dispatch and authenticated result path are verified, model work is
manual and production publishing remains blocked by the existing reviewed gate.
