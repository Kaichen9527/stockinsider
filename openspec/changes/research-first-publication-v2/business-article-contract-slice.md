# Business article v2 — pure contract slice

This implements the approved first-publication business article branch without
activating a route, model or publication. The v1 validator remains unchanged.
Input is a trusted server's complete revision/request and selected public source
descriptors. These descriptors must be resolved from the sealed source revisions;
they are not model input authority. The pure function revalidates the current
compiled complete-input mapping and actually reruns the fixed AUO/EMC calculator.
Its result must equal the sealed calculation, including the original limitations.

The closed author shape has the seven focused chapters, a structured summary,
catalysts with transmission/countercase/falsifier, paragraph IDs/references,
valuation sensitivities and optional collapsed company background. References
point to selected source row hashes/locators, printed observations, calculated
nodes, assumptions or explicit sealed gaps. Printed PDF page numbers are not
financial observations. Industry-only sources and rumor paragraphs cannot supply
company production/order stage support. This checks structure and provenance;
whether prose is true and citations actually support it still requires the
independent reviewer. A reported paragraph is not automatic official confirmation.

Tables accept references instead of model-supplied values. Values, units, periods,
scenario IDs and classifications come from the same recalculation or printed
observation. Future-four-quarter and complete forecast-year EPS are separate;
partial2026 cannot be presented as a full-year forecast. Negative/zero EPS has
no P/E-derived price. Multiples remain explicitly uncalibrated sensitivities with
no target price, retaining discount assumptions. No new orders, physical capacity,
normalized EPS or YTD bridge are inferred. Date-only/unknown source precision
keeps a null instant; observed/admitted cutoffs and original author deadlines
remain required. Immutable input clocks are not refreshed.

The returned hash binds prose, references, public descriptors, recomputation,
table cells, sensitivity values, input identity, validator version and calculator
execution hash. Returned data has no mutable aliases to the caller. No credential,
principal or canonical job request is projected. All publication/investment
capabilities remain false. This pure function cannot check live DB rights or
assignment fences; the future guarded receive/publication path must do that.

Acceptance uses both actual pinned financial file sets with explicitly synthetic
private claim/source/revision fixtures. It is not a DB sealing, role-execution or
publication receipt. Required negative cases cover altered sealed results even
with recomputed hashes, wrong identities, v1 downgrade, arbitrary executables,
fabricated table values, missing order/normalized nodes, assumption promotion,
withdrawn/superseded/wrong-company/late sources, invented date instants, period
mixing, duplicate paragraphs, credentials in prose and original lease expiry.
No source SQL, financial core, protected gate or production state changes here.
