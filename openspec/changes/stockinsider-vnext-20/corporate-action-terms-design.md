# Corporate-action terms and immutable target baseline

Source candidate within VN07/VN08, not a production migration or independent approval.

The existing corporate-action cache supplies event identity and reference prices,
not shares/cash/rights terms. Neither its adjustment factor nor reference-price
ratio may populate those terms. This change adds a finite disclosed-line adapter
for original public MOPS revisions. It requires each of the nine named fields
exactly once: issuer, effective date, action kind, old/new shares, cash dividend,
cash return, subscription cash per old share, and currency. Absence is a gap,
including absent zero cash. Alternative prose/layouts remain unsupported; this
is not exhaustive MOPS coverage. Originals and existing financial enums stay intact.

A private append-only publication/event/stock use-policy supplies permission,
not truth. The reader independently checks current source/publisher identity,
the full publisher allowlist row, original revision family/head, original body
canonical hash, MOPS host, issuer/date/kind and exact field spans. Revocation is
permanent for that source/event; no HTTP/model can write permission. The provider
receives the full permitted original body alongside finite numeric spans so that
independent review can detect contradictory context. Synthetic fixture metadata
does not establish actual source rights or semantic review.

Author reads are bound to the existing job/principal/execution and original
deadline. Both ordinary preparation and read/resume use the same projection.
Every new preparation, including direct service RPC insertion through the
original function, must satisfy a private BEFORE INSERT guard. The original
source callgraph rechecks prepared receipts/current originals at provider use and
publication. Unprepared stored lifecycle state is distinguished by actual
preparation rows, never a caller `prepared`/`validated` flag. Legacy historical
rows are retained; an absent old terms declaration cannot conceal newly effective
terms at current provider/publication use.

The old reviewed target is never overwritten. A separate private original-target
source validator is an exact complete copy of the prior current source/forecast/
roster validation body. Only the immutable-target path calls it; it is not a
provider/publish bypass or public skip-live API. New target use still validates
the current official quote/action interval and every new terms receipt. The
original source/review/provider/input/revision/contra gates remain in the body.

Supported calculation: zero-cash, zero-subscription `par_value_change`, with
explicit old/new share counts, divides the original per-share scenarios by the
ordered share-count ratio. Only exact results within the six-decimal domain are
emitted; unsupported precision is a gap, never rounded. The result binds the
original revision/input/output/baseline hash and ordered current terms hashes.
The SQL target-exit proof remains recomputed by the original atomic exit path.

## CA-D1: unresolved product decision

Concrete proposal for review: retain a **price-only per-share target**, display
cash distributions separately, and do not treat cash distributions/subscription
payments as automatic target achievement. This is **not approved**. Until a
review defines each cash dividend, cash reduction and rights-subscription case,
`target_cash_or_rights_intent_decision_required` is returned. No total-return or
cash-subtraction formula is implemented.
