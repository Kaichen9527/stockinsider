# TWSE and TPEx foreign-cash replay

The offline exchange replay accepts five increasing report dates. Each requires one TWSE BFI82U report and one TPEx dataset 11743 report in New Taiwan dollars. It selects each venue’s foreign-and-Mainland-investor row excluding foreign dealers and preserves the exact observed bytes, receipt hash and acquisition timestamp during the replay. It verifies buy minus sell for every row and reconciles the report subtotals. The archive contains receipts only. The code never infers TWD from share counts.

The TWSE date must appear in the MS950 report itself. The UTF-8 export with no published date in the body is outside this replay contract. The parser checks stated HTTP status, exact dated URL, encoding, byte bounds and SHA-256. Missing, duplicate or cross-venue mismatch fails the replay. Official publication time remains unknown when the source does not provide it. Material collected after the original decision cutoff cannot support that decision.

The official TWSE catalogue lists separately timed products. Its public trading-information FAQ describes agreements for value-added transmission or use by others. The checked TWSE OpenAPI catalog did not list BFI82U. The ability to read this public report does not establish applicable rights for automated reuse and publishing derived production status. The two-market replay does not acquire scheduled work, persist source facts or unlock market scoring. The remaining material gap is documented TWSE permission for the exact daily product and intended use, plus point-in-time database receipts and calendar alignment.
