# Source-bound catalyst cancellation: finite execution design

This implements the already-approved immediate exit on verified catalyst cancellation. It is not a new investment strategy or an acceptance waiver. Existing v2/v3 prompts, numerical weights, quota/lease/clock policy and source rights stay unchanged. The optional server-selected v4 worker profile adds an explicit relation between two original official statements; `not_met`, metadata, numerical one, keywords and arbitrary operator evidence do not authorize cancellation.

The frozen provider input contains a bounded server-derived cancellation context. With no previous publication the original planned statement and later cancellation statement must both be in the current frozen evidence. With a previous publication, the latest retained revision/input/output/catalyst claim and original evidence are additionally bound. The latest original catalyst source must also exist identically in the current frozen input and pass current rights/withdrawal and original availability. No active historical reader is bypassed and no caller provenance flag exists. A retained article without a usable source-bound catalyst remains an explicit gap; it is not silently treated as first research. Context claims/evidence each <=4, full existing request envelope/depth remain authoritative; excess rejects, never truncates.

Both configured roles read both originals; the distinct reviewer echoes the complete relation and assesses an explicit reported cancellation. Structural quote/date/issuer/hash/ordering validation is deterministic; actual semantic support still requires real source/model review, not a fixture verdict. First and retained modes use exact source locators and no language-specific cancellation parser.

An owner-only database checker derives authority from actual immutable preparation, the latest server baseline, exact original source extraction, both completed normalized provider journals, independent principal/execution/response identity, original request hashes, deadlines and source-read order. No public RPC, service-role checker grant, role, table, budget or second source authority is added. Unknown authority cannot exit. Existing direct operator cancellation exits must recompute the same proof instead of accepting a nonempty evidence list.

On a valid cancellation review, the existing reviewer identity internally publishes through the guarded publish branch within the same original transaction/mutex. Proof is computed before mutation, forces an unqualified retained revision, records the proof and atomically exits membership; immutable historical research remains, no attempt/provider call is refunded or created. Ordinary reviews retain their original flow. Replays return the original revision/clock; response loss is uncertain and uses explicit reads, never repeated provider dispatch.

Required new acceptance: genuine full candidate COMMIT/OID/ACL/catalog checks; legitimate input->author->different reviewer->one unqualified history + atomic exit; literal/boolean/numeric fake proof denial; different source/date/issuer/quote/baseline/prompt/journal/rights withdrawal denial with whole-state equality; exact replay and no extra attempt/provider charge. Source contract tests do not constitute PG/semantic/production acceptance. Local fresh PG/fullbuild currently not admitted; ordinary hosted execution must identify its exact runtime source separately. All old REDs and successes keep their original subjects.

This slice does not implement verified contraindication, competitive/risk scoring, complete source-window/volume, numeric forecast authority or real semantic publication. These remain named work. No merge/deploy/scheduler resumption is authorized.
