# 個股圖表的官方交易日與價格依據

T06／T08。新私有選取器從已存在的榜單成員及評分證據定位交易所、標的與原 cutoff。依官方交易日曆選取三個曆年及顯示開始前 239 個已完成交易日。相同底層保留 240／520 日呼叫及既有版本雜湊，獨立的圖表範圍以自己的雜湊識別。找不到官方日曆時留缺口。

歷史原始 OHLC 沿用既有機會價格證據讀取，依每次最多 900 天的既有邊界分段。逐日核對最新觀測與交易日版本、資料時鐘及價格合法性。最近 240 筆須與榜單選定的交易日及原始觀測完全一致。缺漏、同優先度衝突或版本不符都回傳空值。輸出為私有依據，尚無公開 RPC 或 API 可直接取得。

PostgreSQL 17.11 發現原榜單 SQL 日曆條件的 CASE 比較必須以括號括起。修正只補括號，既有條件與判斷維持同義。新增遷移會以修正後的原函式內容雜湊確認可安裝的前置版本。

後續須將完整公司行動、成交量及可公開的來源證據綁到同一圖表版本，讓既有 writer 在發榜交易中保存圖表與保留資料的引用。完整正例及缺口均需真實來源驗收。正式圖表契約仍可回傳 null，既有榜單資格、排程、額度、HOLD 和發布審查繼續適用。
