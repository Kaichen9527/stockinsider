# 榜單凍結價格的個股圖表

T06 / T08。個股詳情以同一次榜單的日 K 及交易日為輸入，接收獨立的圖表雜湊以及相符的價格、交易日曆、公司行動版本。視窗從榜單交易日的三年前開始，使用之前 239 個交易日暖機。暖機資料用於移動平均。日、台灣曆週及曆月共用既有分組。成交量以股計，缺值留白，週、月只在構成日都有成交量時加總。UTC 傳輸時鐘和台灣交易日期各保留原用途。

新版 DTO 的 `chart` 可維持 `null`。顯示用資料限定日期與 OHLCV，拒絕版本錯配、非遞增交易日、未來資料、暖機筆數不符、無效 OHLCV 或任意額外欄位。圖表重用 StockChart。週期切換只讀取頁面上的凍結資料，讀取仍用原有榜單 RPC。不改排名資格、公式、來源或寫入權限。

後續需要把三年及暖機官方日曆、價格、成交量、公司行動及可公開權限接到既有 writer，並在發榜時凍結完整圖表及其來源版本。現有 240 個評分交易日的股票資料與 11764 close-only 私用資料均不足以證明該圖表。正式 RPC 仍回傳 `chart: null`，保留待有正規資料時的原始缺口。
