# Official roster trading-invalidity exit candidate

This additive source candidate derives deterministic trading invalidity from the existing official instrument roster. It does not establish financial qualification, source-bound semantic contradiction/catalyst cancellation, forecast authority, formal reviewer approval or production installation.

`vnext_trading_invalid_current_v1(text,text)` is a new private SECURITY DEFINER function owned by `stockinsider_vnext_owner`, executable by that owner alone. It uses only the 12 `stock_instruments_v3` columns and SELECT-only RLS policy already added by the target-exit candidate. The installer asserts the existing owner/RLS/policy, exact needed column types/ACL and hardened vNext owner; it adds no old-table permission, policy, role or ownership change.

The checker binds the actual non-exited member and current input hash. At most 1000 retained rows for its symbol are considered; overflow is a gap. It checks the full official provider/exchange/version/common-stock tuple, finite ordered source/recorded clocks, unique stock identity, no conflicting latest recorded authority, and the latest row's actual current validity interval. A current conflicting stock-to-symbol mapping also defers. Only an explicit `suspended` or `delisted` latest row produces a proof. Active, missing, future, expired interval, unknown or ambiguous authority never produces an exit. No arbitrary source-age expiry is invented; an otherwise current valid official row is not made stale solely by elapsed time.

The proof retains the exact selected 12-column roster identity and clocks, current member state/input, canonical member-evidence hash, canonical roster hash and canonical whole-proof hash. All hashes are computed by the existing database canonicalizer; no caller boolean, timestamp refresh or TS numeric/timestamp re-encoding is authority.

The existing `vnext_target_command_v1(text,jsonb)` keeps its configured operator, enabled-mode, common mutex, all-active bound and closed request. It evaluates invalidity before publication, valuation or quote lookup, including unpublished researching members. A confirmed proof invokes existing `exit/trading_invalid`; otherwise the original target path continues unchanged. Exactly one original-shape observation per member is returned, at most 20 with unique symbols and the original policyVersion. Invalidity deferral reasons remain in the private checker/source contract; the public receipt gains no fields.
