## Architecture closure

V3.18 has one bounded source-led pipeline: approved public acquisition emits
typed terminal outcomes; entity-linked source claims nominate candidates; the
candidate ledger retains complete last-good source-linked candidates through a
bounded twenty-session window; official facts, valuation and technical evidence
enrich only those candidates; the sole decision revision emits a compact
projection and an exact matching full dossier. There is no reverse path by
which all-market official fetches, a seed list, paid InvestAnchors text or
Telegram content can nominate a card.

Cardinality and authority boundaries remain closed. Retained candidates are
allocated before new candidates, the overall funnel remains bounded at 60, and
each fresh candidate deferred by a retained reservation receives a terminal,
typed reason. The compact payload excludes the full dossier; revision/card
unions deduplicate equal revisions and fail closed on a window conflict. Web
detail consumes the same revision ID as Landing. Missing per-card authority
renders safe research-only detail rather than blanking the projection or
manufacturing an action.

The V3.18 ledger migration is additive: it wraps the existing leased claim
function, reuses the predecessor terminal result, bounds retained rows,
restores the original owner/grants and revokes temporary schema-create
capability. It contains no drop, truncate or data rewrite. The runtime bundle
tracks dossier code, and the V3.11 signed host pin protects the normal host
runner path. The base-owned external gate is itself controlled by `main` and
reads only immutable V3.18 evidence refs, preventing candidate code from
substituting review data.

No production migration, source write, runtime activation, Web deployment,
password reset, credential rotation, LINE, dispatch, automatic trading or
Promotion occurred in this review. Action authority remains disabled until
matching reviewed migration, runtime, manifest, producer and Web identities are
proved at the later operational gate.
