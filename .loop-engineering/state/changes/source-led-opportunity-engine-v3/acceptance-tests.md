## Required Test Layers

- Unit: entity linking, dedupe, quotas, TTL, horizon scores, regime completeness, valuation invariants and action precedence.
- Contract: canonical source outcomes, V3 public payload, legacy compatibility and bounded egress.
- Integration: guarded opportunity runs, terminal-run atomicity, immutable snapshots and outcome labeling.
- Performance/resource: prove durable job/page execution stays within SQL, payload, memory and candidate bounds under interruption.
- Security/governance: principal-bound authority, replay/blind-review isolation, no anon fallback/raw connector text, model boundary and acceptance traceability.

## RED Baseline

Before implementation, executable characterization must demonstrate these failures against current behavior:

1. source rows can be written while no linked/rejected candidate accounting exists;

## Shadow Promotion Evidence

Promotion evaluation requires a reproducible point-in-time backtest over at least 120 qualifying run dates and at least 20 live cohorts whose 20-session outcomes have matured. Verification Gate then requires:

- source documents have typed terminal outcomes and no unexplained loss;
- direct-source candidate-link precision and recall are reported from reviewed samples;
- V3 candidate Precision@20 and NDCG@20 improve by at least 10% relative to the frozen legacy baseline;
- worst-decile maximum adverse excursion is not worse by more than two percentage points;
- no authoritative model influence occurred;
- no automatic migration/deploy/promotion occurred.

Twenty calendar or trading days of runtime alone is not promotion evidence. A missing or unreproducible legacy baseline lock fails closed.
