# Sector Taxonomy Contract: source-led-opportunity-engine-v3

Version: `tw-sector-taxonomy-v3.0`

Every roster-eligible TW common stock has at most one point-in-time canonical sector assignment in additive `stock_sector_assignments_v3`. Authority is the listing exchange's official industry code. `sector-taxonomy-map-v3.json` is the complete approved code-to-key baseline for both provider namespaces; keys outside that file map to `unknown` and cannot be invented by implementation. Free-form `stocks.sector`, source text and assistive models are display hints only.

The assignment row stores assignment authority id, stock id, market, official industry code, canonical sector key, provider, source timestamp, valid-from/to, taxonomy version, `status=active|inactive` and database-generated `recorded_at`. Writes flow only through the fixed runner principal's server-owned taxonomy-ingestion mode in `auth-principal-contract.md`; provider and mapping version are allowlisted, not request-selected. At cutoff, first apply the assignment stream `[stockId,market]` algorithm in `authority-supersession-contract.md`; only `effective_active` membership supplies a sector. A later inactive event revokes the older assignment, a later active event reactivates/corrects it, and a later-learned historical assignment cannot affect an earlier run. If no effective active assignment exists, the sector key is exactly `unknown`. Cross-market or latest-tie conflicts are fail-closed, not an arbitrary choice.

`taxonomyMapHash = SHA256(UTF8(RFC8785(sector-taxonomy-map-v3.json)))`. Post-supersession assignment rows are `[assignmentAuthorityId,stockId,market,officialIndustryCode,canonicalSectorKey,provider,sourceTimestamp,validFrom,validToOrNull,taxonomyVersion,status,recordedAt]` with manifest terminal code `effective_active|revoked_or_expired`, sorted stock ID, market, valid-from, source timestamp, recorded-at, official code, provider and authority UUID. A latest differing tie is `authority_revision_conflict`; the 20,001st selected stream fails `roster_volume_exceeded`. Under `manifest-storage-contract.md`, `sourceCutoff,taxonomyMapHash,rowCount` are the `taxonomy_assignment` header fields, row count includes every terminal stream and those rows populate `rows`. `taxonomyAssignmentManifestHash` is the universal root hash, and every source/enrich/evaluation run binds both hashes; consumers use only `effective_active` and no parallel assignment-array hash exists.

Canonical keys are exactly the JSON mapping values plus `unknown`; `finance_insurance` is the financial-method sector. Sector quota treats `unknown` as one ordinary group. Sector-cycle percentiles compare a sector's aggregate with all non-`unknown` canonical sectors having complete point-in-time inputs at the same cutoff; at least eight sectors are required. Ties and percentiles follow `scoring-contract.md`.
