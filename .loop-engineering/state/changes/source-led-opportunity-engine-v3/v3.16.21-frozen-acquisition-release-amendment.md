# V3.16.21 frozen acquisition and single-release closure amendment

Owner: `source-led-opportunity-release-v3.16.21`

## Authority and bounded scope

This is the only active successor release after the merged V3.16.20 code gate.
PR #89, its final protected root, Requirements and Architecture evidence are
historical inputs and are not rerun. V3.16.21 receives exactly one fresh
Requirements review and one independent Architecture review after this contract is
frozen. A repeated finding class is redesigned at its root instead of creating an
unbounded numbered review sequence.

The user authorizes the additive migration, tracked producer activation, source
writes and matching Vercel production deployment after the exact review and Code
Gate pass. Database password reset, credential rotation, LINE, dispatch, automatic
trading, V3 public activation and Promotion are explicitly outside authority.

## Frozen provider acquisition

Every provider call is represented by an append-only
`provider-acquisition-revision-v3.16.21` envelope. Its request identity binds the
provider, stage, source cutoff and bounded normalized request material. The envelope
records the real whole-second `fetchedAt`, response-set SHA-256 and byte count,
normalized payload hash, terminal status, evidence root and action eligibility.
`fetchedAt` is never copied from `sourceCutoff`.

The worker checks durable acquisition storage before network access. A completed
request key is immutable and reused across retry or a later same-input run. A
different response for the same key is quarantined as a conflict and fails closed.
Partial retry acquires only absent request keys. Candidate, facts, valuation,
decision and projection stages consume the frozen normalized envelope, never a new
live provider response. An evaluation earlier than `fetchedAt` cannot use the
envelope; historical backfill may inform current/future evaluation but cannot alter
past point-in-time cohorts.

For the current run, the database-owned evaluation clock is the later of the run
start and the latest immutable acquisition `fetchedAt`. This does not rewrite either
timestamp: it permits current research to consume evidence that has actually
arrived while making retry output deterministic. Action authority commits a sorted
hash of the complete provider lineage used by the run, including the legacy capture,
approved-source terminal set, optional coarse discovery and official fact fetch.
Missing, incomplete, future or action-ineligible mandatory lineage disables action.

## Effective health and research visibility

Public Radar and authenticated internal health derive the same effective state from
checksum, trading-session freshness, runtime doctor, consumer/producer commit,
manifest, migration and frozen acquisition authority. Any mismatch removes the
actionable decision envelope and disables legacy action fields. Checksum-valid
last-good research remains visible and navigable through a research-only detail;
checksum conflict is the only condition that clears research.

Every visible card links either to the exact `decisionRevisionId` or to a
research-only detail with explicit blockers. A missing authoritative decision is
not translated into `avoid` or a buy recommendation. Source outcomes remain typed;
OAuth absence and zero transcripts/documents cannot be reported as success.

## Release and rollback

The exact reviewed tree must pass migration apply-twice, frozen provenance,
health, valuation/technical/action regressions, typecheck, lint, build, Playwright,
performance, model-runner and protected root. Production then applies the additive
migration with the exact reviewed CLI, activates the same tree, completes two
terminal producer invocations, publishes a matching compact projection and deploys
the same release identity to `stockinsider-three`.

Read-only smoke and Safari must prove nonzero unique research, navigable cards,
revision consistency, disabled `/api/opportunity-v3`, payload/HTML bounds and latency
thresholds. Failure rolls the Vercel alias and runtime back; additive database
objects remain and the scheduler is stopped. Evaluation promotion stays
`blocked/non_fabricated_elapsed_cohorts_unavailable` until real 120/20/252 cohorts
mature.
