# V3.17 source-led actionability and research-detail amendment

Version: `source-led-opportunity-actionability-v3.17.0`

Status: `implementation_in_progress`

## Bounded scope

This successor release closes three observed production regressions without
loosening formal action authority: inaccessible CTA contrast, loss of
support/breakout research cards during readonly health, and a research-only
detail that discarded its immutable snapshot.

The release is source-led. A candidate must originate from a recent, linked,
authorized source revision. TWSE/TPEx data may verify the symbol, compute
facts, benchmarks, liquidity and valuation, but cannot nominate a candidate.
No minimum number of `buy` or `accumulate` cards is permitted.

## Source boundaries

- InvestAnchors is internal methodology research only. The product, runtime,
  repository, logs and model inputs may not contain its paid text, excerpts,
  screenshots or derivative summary. It is not a candidate source.
- Telegram is `not_authorized`; no Telegram content is acquired, entity-linked,
  persisted or sent to a model.
- Podcast, YouTube and Threads require their stated API/transcript/OAuth
  authority. `metadata_only`, `auth_failed`, `provider_failed`, zero writes and
  login-wall results remain terminal non-thesis outcomes.

## Contract

`DecisionEnvelope` remains the only executable-action authority. V3.17 adds
`ResearchNextStep` and `ResearchSnapshot` as immutable, non-executable
research presentation. A checksum-valid stale card may show `wait_refresh`,
`wait_breakout` or `wait_reclaim` plus its exact snapshot, but cannot show a
buying action. A missing data axis is a per-card gate; global health only
disables actions for lineage, integrity, runtime, manifest, migration or
release-identity mismatches.

The producer order is frozen acquisition → persisted deterministic union →
facts/valuation/technical/liquidity → decision → compact projection. Same
frozen inputs must produce identical candidate, decision and projection hashes.

## Acceptance

1. Light/dark CTA computed contrast is at least 4.5:1 at desktop and mobile.
2. A source-linked `at_support` card with incomplete formal data appears in
   `等待條件` as `wait_refresh`, never as `buy` and never disappears into an
   undifferentiated empty page.
3. Every V3.17 visible card has one immutable decision revision and a
   same-revision detail. A research-only snapshot includes provenance,
   valuation/fundamental/technical values or precise missing values, next step,
   and gate waterfall.
4. Legacy fields are compatibility projections of the same envelope; they do
   not independently nominate an action or lane.
5. API exposes additive `researchSnapshot`, `researchNextStep`, `gateWaterfall`,
   `sourceWatermark`, `authorizationStatus`, and `releaseIdentity` fields within
   payload limits.
6. No paid InvestAnchors content or Telegram-derived text appears in tracked
   artifacts, source documents, projections, logs, fixtures or model inputs.

## Gate discipline

Exactly one fresh Requirements review and one independent Architecture review
will be run for this frozen V3.17 contract. Findings with the same root cause
are repaired in one bounded tree; a second recurrence triggers root redesign
rather than a new numbered review loop. Existing V3.16.21 historical reviews
are evidence only and are not relabelled as V3.17 approval.

Production is allowed only after the exact implementation review, repair/full
range closure, Code Gate and Shadow Activation Gate pass. It excludes database
password reset, credential rotation, LINE, dispatch, automatic trading and
Promotion. Evaluation governance remains
`blocked/non_fabricated_elapsed_cohorts_unavailable` until real cohorts mature.
